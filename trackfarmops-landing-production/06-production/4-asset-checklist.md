# Export Validation

Every exported asset must satisfy:

☐ Correct naming convention

☐ Optimized file size

☐ Correct dimensions

☐ Transparent background where required

☐ SVG paths optimized

☐ AVIF/WebP generated for raster images

☐ No embedded metadata

☐ Pixel-perfect rendering

---

# Engineering Validation

Before integration:

☐ Asset imported successfully

☐ No rendering issues

☐ Responsive scaling verified

☐ Animation compatibility verified

☐ Accessibility requirements satisfied

☐ Lazy loading configured where applicable

# Final Principle

Every asset should earn its place in the experience.

Nothing should exist purely for decoration.

Every illustration, icon, dashboard element and animation asset should help tell the story of how TrackFarmOps transforms Nigerian farm management from paperwork, uncertainty and operational chaos into clarity, efficiency and scalable growth.
