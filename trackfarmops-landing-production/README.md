# TrackFarmOps Landing Production Bible

> Version: 1.0.0
> Status: Pre-Production
> Product: TrackFarmOps
> Production Type: Cinematic Scrollytelling Landing Experience
> Framework: Next.js 15 + React 19 + TypeScript
> Animation Engine: GSAP + ScrollTrigger
> Styling: TailwindCSS
> Design System: Custom
> 3D: React Three Fiber (Only if required)
> Performance Target: 60 FPS
> Primary Devices:
> - Desktop
> - Tablet
> - Mobile

---

# Mission

Create the most immersive agricultural SaaS landing page in Africa.

This is **not** a marketing website.

It is an interactive visual story that transforms the emotional experience of farm management—from operational chaos to digital clarity—through cinematic motion, meaningful interaction, and world-class product presentation.

Every scroll should advance the story.

Every animation must communicate purpose.

Every visual decision must reinforce TrackFarmOps as the Farm Operating System for modern agriculture.

---

# Creative Vision

Visitors should not feel like they are browsing a SaaS website.

They should feel like they are experiencing an interactive short film.

The page should communicate the product's value even if the visitor never reads a paragraph of text.

Scrolling should replace traditional storytelling.

Motion should replace lengthy explanations.

Visual transformation should replace feature lists.

---

# Guiding Principles

## Story First

Every animation must tell part of the story.

Never animate purely for decoration.

---

## Motion With Meaning

Motion communicates information.

Objects move because something caused them to move.

Transitions always have narrative purpose.

---

## Simplicity Wins

Minimal interface.

Minimal copy.

Maximum clarity.

Avoid visual clutter.

---

## Cinematic Thinking

Design every scene like a film frame.

Consider:

• Composition
• Camera movement
• Lighting
• Depth
• Rhythm
• Focus

---

## Product Before Marketing

Never exaggerate.

Never create fake dashboards.

Never invent capabilities.

Every UI shown should represent realistic TrackFarmOps functionality.

---

## Performance First

Beautiful experiences should remain lightweight.

Target:

60 FPS

Fast first paint

Optimized assets

Lazy-loaded scenes

GPU-friendly animations

Minimal layout shift

# Production Standards

All assets must:

✓ Be production quality

✓ Be reusable

✓ Be optimized

✓ Follow the design system

✓ Maintain consistent lighting

✓ Maintain consistent perspective

✓ Maintain consistent color grading

---

# Engineering Standards

No inline GSAP animations.

Every scene owns its own animation timeline.

Animations must be modular.

Components must be reusable.

Performance must be measurable.

Accessibility is mandatory.

---

# Collaboration Rules

This repository serves as the single source of truth.

Design decisions originate from this production bible.

Engineering follows production specifications.

Assets follow the Asset Bible.

Motion follows the Animation Bible.

No implementation should diverge from these documents without updating the specification first.
