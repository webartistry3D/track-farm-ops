# Project Context
## TrackFarmOps Landing Experience

TrackFarmOps is a premium farm management platform designed to help commercial farms digitize operations, improve productivity, and make data-driven decisions.

This landing page is a cinematic, scroll-driven product experience that visually demonstrates the journey from manual farm management to intelligent digital operations.

## Project Vision

Build an immersive landing page that feels more like an interactive film than a traditional SaaS website, using storytelling, animation, and thoughtful UI to communicate the value of TrackFarmOps.

## Core Narrative

**Calm → Chaos → Order → Farm Lifecycle → Analytics → Scale → Call to Action**

Every scene should naturally transition into the next, allowing users to understand the product through interaction rather than lengthy explanations.

## Technology Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Lenis
- SVG illustrations
- Blender-rendered assets
- Figma design system

- Keep code modular and reusable.
- Prioritize performance, accessibility, and responsiveness.

Every contribution should:

- Support the overall narrative.
- Feel polished and cinematic.
- Be production-ready.
