# Workflow
## Windsurf Development Workflow

Follow this workflow for every implementation task.

## Step 1 — Understand

- Read the assigned task carefully.
- Review the relevant Production Bible documents.
- Identify dependencies and affected components.
- Clarify uncertainties before implementation.

## Step 2 — Plan

- Break the task into small, manageable units.
- Identify reusable components and hooks.
- Consider animation, responsiveness, performance, and accessibility.

## Step 3 — Build

- Implement only the requested scope.
- Follow the established architecture and coding standards.
- Keep components modular and reusable.

## Step 4 — Verify

Confirm that the implementation:

- Matches the approved storyboard.
- Follows the design system.
- Adheres to GSAP patterns.
- Is responsive across breakpoints.
- Meets accessibility and performance requirements.

## Step 5 — Refine

- Simplify where possible.
- Remove unnecessary code.
- Optimize animations and rendering.
- Ensure naming and structure remain consistent.

## Step 6 — Deliver

Provide:

- A brief implementation summary.
- Production-ready code.
- Integration notes, if applicable.
- Any assumptions or limitations.

## Rules

- Build one scene at a time.
- Never implement undocumented features.
- Never compromise maintainability for speed.
- Treat the Production Bible as the single source of truth.
- Leave the codebase cleaner than you found it.
