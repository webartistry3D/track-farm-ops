# Workflow
## Devin Execution Workflow

Follow this workflow for every task.

## Step 1 — Understand

- Read the assigned task.
- Review relevant Production Bible documents.
- Identify dependencies.
- Clarify ambiguities before coding.

## Step 2 — Plan

- Break the task into logical components.
- Identify reusable modules.
- Define animation requirements.
- Consider performance and accessibility.

## Step 3 — Implement

- Write clean, modular, production-ready code.
- Follow the project architecture.
- Build only the requested scope.

## Step 4 — Validate

Verify that the implementation:

- Matches the storyboard.
- Follows the design system.
- Uses approved GSAP patterns.
- Is responsive.
- Is accessible.
- Meets performance standards.

## Step 5 — Refine

- Remove unnecessary complexity.
- Optimize animations.
- Refactor where appropriate.
- Ensure consistent naming and structure.

## Step 6 — Deliver

Provide:

- A brief implementation summary.
- Production-ready code.
- Any required setup or integration notes.
- Any assumptions or known limitations.

## Rules

- Complete one scene before starting another.
- Never implement undocumented features.
- Never compromise performance for visual effects.
- Treat the Production Bible as the single source of truth.
- Leave the codebase cleaner than you found it.
