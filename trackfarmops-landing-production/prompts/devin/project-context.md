# Project Context
## TrackFarmOps Landing Experience

TrackFarmOps is a modern farm management platform built to help commercial farms digitize and streamline their daily operations. The landing page is not a traditional marketing website—it is an interactive, cinematic product experience that tells a visual story.

## Project Goal

Demonstrate the transformation from fragmented, manual farm operations to an intelligent, data-driven management platform through immersive scroll-driven storytelling.

## Core Narrative

**Chaos → Order → Intelligence → Scale**

Visitors should understand the product primarily through visuals, motion and interaction, with text serving as supporting context.

## Technology Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Lenis
- Framer Motion (only where appropriate)
- SVG illustrations
- Blender-rendered assets
- Figma UI components

## Working Method

- Build incrementally.
- Complete one scene before starting the next.
- Never skip documentation-defined requirements.
- Prioritize maintainability, performance and accessibility.
- Preserve narrative continuity across all scenes.

## Success Criteria

Every implementation should:

- Match the approved storyboard.
- Feel cinematic and premium.
- Be production-ready.
- Be performant on desktop and mobile.
- Remain faithful to the TrackFarmOps Production Bible.
