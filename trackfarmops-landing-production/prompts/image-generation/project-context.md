# Project Context
## TrackFarmOps Landing Experience

TrackFarmOps is a premium farm management platform that transforms fragmented farm operations into a unified, intelligent digital ecosystem.

The landing page is a cinematic, scroll-driven storytelling experience where illustrations and visual assets communicate the product journey with minimal reliance on text.

## Project Vision

Create a cohesive library of production-quality illustrations and visual assets that reinforce the narrative and elevate the TrackFarmOps brand.

## Core Narrative

**Calm → Chaos → Order → Farm Lifecycle → Analytics → Scale → Call to Action**

Every illustration should support this progression and integrate seamlessly into the animated experience.

## Visual Direction

- Modern AI SaaS aesthetic
- Stylized semi-realistic illustrations
- Clean geometric forms
- Consistent lighting and color system
- Minimal visual noise
- Animation-friendly compositions

## Asset Requirements

Generate assets that are:

- Consistent across all scenes
- Suitable for SVG or transparent PNG export
- Layered where animation requires it
- Optimized for web performance
- Faithful to the approved art direction

## Reference Documents

Always follow:

- `01-story/`
- `02-art-direction/`
- `03-assets/`
- `04-animation/`
- `05-engineering/`
- `06-production/`

These documents define the project's narrative, visual language, animation requirements, and production standards.

## Success Criteria

Every generated asset should:

- Strengthen the story.
- Feel premium and memorable.
- Match the established illustration style.
- Be ready for production with minimal editing.
- Integrate naturally into the TrackFarmOps cinematic experience.
