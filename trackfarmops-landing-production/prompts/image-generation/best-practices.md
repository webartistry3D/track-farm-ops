# Best Practices
## Image Generation Standards

Apply these principles to every asset created for the TrackFarmOps Landing Experience.

## Visual Consistency

- Follow the approved illustration style.
- Maintain a unified visual language across all scenes.
- Use the defined color system, lighting, and composition rules.
- Ensure every asset feels like part of the same product.

## Asset Quality

- Produce production-ready artwork.
- Keep assets clean, sharp, and scalable.
- Use transparent backgrounds where appropriate.
- Create layered assets when animation requires independent elements.

## Composition

- Prioritize clarity over complexity.
- Keep focal points obvious.
- Avoid unnecessary decorative details.
- Design with animation in mind.

## Animation Readiness

- Separate movable elements into logical layers.
- Preserve clean silhouettes.
- Avoid baked-in shadows or effects that limit animation.
- Ensure assets work well with GSAP transforms.

## Performance

- Optimize for SVG whenever practical.
- Minimize unnecessary vector points.
- Keep file sizes lightweight.
- Follow the project's export guidelines.

## Brand Consistency

- Reinforce the TrackFarmOps identity.
- Reflect modern agricultural technology.
- Balance realism with simplicity.
- Maintain a premium AI SaaS aesthetic.

## Collaboration

- Stay within the requested scope.
- Do not introduce undocumented visual elements.
- Follow the Production Bible before making creative decisions.
- Keep outputs easy to integrate into Figma, Blender, and the web.

## Output Standard

Every generated asset should be:

- Production-ready
- Animation-friendly
- Visually consistent
- Optimized for web
- Scalable
- Easy to integrate
- Fully aligned with the TrackFarmOps Production Bible
