# Workflow
## Image Generation Workflow

Follow this workflow for every asset generation task.

## Step 1 — Understand

- Review the requested asset.
- Read the relevant Production Bible documents.
- Identify the scene, purpose, and animation requirements.

## Step 2 — Plan

- Determine composition, perspective, lighting, and style.
- Ensure consistency with existing assets.
- Consider layering if animation is required.

## Step 3 — Generate

- Create the asset following the approved visual language.
- Maintain stylistic consistency.
- Optimize for production use.

## Step 4 — Validate

Confirm that the asset:

- Matches the storyboard.
- Follows the art direction.
- Supports the planned animations.
- Aligns with the color system and illustration style.

## Step 5 — Refine

- Remove unnecessary details.
- Improve clarity and readability.
- Ensure the asset remains animation-friendly.
- Optimize for web delivery.

## Step 6 — Deliver

Provide:

- The final production-ready asset.
- Transparent background where appropriate.
- Layered output if required for animation.
- Any notes on export or usage.

## Rules

- Never deviate from the approved visual style.
- Never mix illustration styles.
- Generate only the requested asset.
- Prioritize consistency, clarity, and production readiness.
- Treat the Production Bible as the single source of truth.
