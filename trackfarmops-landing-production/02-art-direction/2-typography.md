## TrackFarmOps Landing Experience

> Version: 1.0

> Purpose: Typography System & Editorial Direction

---

# Philosophy

Typography should feel invisible.

The visitor should never notice the font.

They should notice how effortlessly information is understood.

TrackFarmOps uses typography to communicate confidence, not decoration.

---

# Primary Typeface

## Inter

Purpose

Primary UI

Body copy

Dashboard

Buttons

Navigation

Forms

Tables

Reason

Inter is highly legible, modern, neutral, and optimized for digital interfaces.

It reflects the personality of enterprise software without becoming sterile.

---

# Secondary Typeface

## JetBrains Mono

Purpose

Numbers

Statistics

KPIs

Financial values

Inventory quantities

System identifiers

Technical labels

Reason

Using a monospace font subtly communicates precision, measurement and operational discipline.

# Font Weight Rules

Regular

400

Narrative copy

Medium

500

Labels

SemiBold

600

Section headings

Bold

700

Hero headings

Never exceed 700.

Avoid Black (900).

Confidence comes from spacing, not thickness.

---

# Editorial Style

Write naturally.

Avoid marketing jargon.

Avoid long paragraphs.

Prefer:

One idea.

One sentence.

One visual.

The page should read like a documentary.

Not a brochure.

---

# Text Density

Every screen should contain as little text as possible.

Motion explains.

Typography reinforces.

Copy confirms.

---

# Alignment

Prefer left alignment.

Center alignment only for:

Hero

CTA

Scene endings

Never justify text.

---

# Line Length

Maximum

70 characters

Ideal

55–65 characters

Long lines reduce readability.

---

# Hierarchy

Hierarchy should come from:

Scale

Weight

Spacing

Never rely on color alone.

---

---

# Motion

Typography should animate with restraint.

Preferred:

Fade

Mask reveal

Slide

Opacity

Tracking

Avoid:

Bounce

Elastic

Spin

Rotate

Overshoot

Typography should never distract.

---

# Accessibility

Minimum contrast:

WCAG AA

Minimum body size:

16px

Never rely solely on color.

Respect user zoom settings.

---

# Typography Principles

Typography should feel:

Calm

Readable

Intentional

Structured

Trustworthy

---

# Final Principle

If visitors notice the font before they notice the message, the typography has failed.
