# Style Reference Board
## TrackFarmOps Landing Experience

> Version: 1.0
> Status: Locked
> Purpose: Establish the definitive visual reference library for every asset produced for the TrackFarmOps landing experience.
> Owner: WebArtistry Creations

---

# Purpose

This document serves as the visual DNA of TrackFarmOps.

It defines the approved visual references that guide:

- AI image generation
- Blender scene creation
- Figma interface design
- Illustration
- Motion design
- Environmental design
- Marketing renders

Every asset must align with these references.

If an asset cannot trace its inspiration back to this document, it should be reconsidered.

# Asset Review Checklist

Before approving any asset, verify:

✓ Matches the established visual language

✓ Feels authentically Nigerian

✓ Uses approved lighting

✓ Supports the current scene

✓ Uses the correct perspective

✓ Can be animated cleanly

✓ Maintains consistent rendering quality

✓ Integrates naturally with the TrackFarmOps UI

✓ Reinforces the emotional arc

---

# Evolution Strategy

As production progresses, this document should be expanded with approved visual references.

Each approved reference should include:

- Thumbnail or screenshot
- Source
- Reason for inclusion
- Related scene(s)
- Related asset category
- Notes for AI prompting

This transforms the document into a living visual library that keeps every contributor aligned throughout the project lifecycle.

---

# Final Principle

Every frame of the TrackFarmOps landing experience should feel like it belongs to the same film.

Whether the asset is generated by AI, modeled in Blender, designed in Figma, or animated with GSAP, the viewer should never perceive differences in style.

Visual consistency is not an aesthetic preference.

It is a product requirement.
