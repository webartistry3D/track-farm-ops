# Purpose

This document contains every approved AI prompt used to generate visual assets for the TrackFarmOps landing experience.

It standardizes prompt structure across all supported AI image models and ensures visual consistency regardless of the generation platform.

No production asset should be generated from an undocumented prompt.

# Universal Prompt Formula

Every production prompt follows this structure:

```
Subject

+

Environment

+

Composition

+

Lighting

+

Visual Style

+

Camera

+

Materials

+

Mood

+

Rendering Quality

+

Negative Prompt
```

This sequence should remain consistent.

---

# Universal Style Prefix

Append this to the beginning of every production prompt:

> Semi-realistic editorial illustration of modern Nigerian commercial agriculture, premium enterprise SaaS aesthetic, clean composition, authentic farm operations, cinematic storytelling, warm morning daylight, soft natural shadows, minimal visual clutter, subtle painterly finish, highly consistent visual language.

---

# Universal Style Suffix

Append this to the end of every prompt:

> Ultra-clean rendering, high detail, realistic proportions, premium composition, layered for animation, no text, no logos, no watermark, consistent lighting, consistent perspective.
